# ぐるり — 周辺自動さんぽ

物件検討用アプリの最小プロトタイプ。地図をクリックすると、その地点の周辺道路を
ひと回りして戻ってくるルートを自動生成し、ストリートビューを自動再生で「歩く」。

## 起動

```sh
python3 -m http.server 8931 --directory ~/Desktop/gururi
```

ブラウザで http://localhost:8931 を開く。

## 使い方

1. 地図を見たい場所でクリック → 藍色の一周ルートが出る(半径は左上で 150〜500m)
2. 「ぐるり歩く」→ 初回は Google Maps API キーを入力
3. ストリートビューが自動で進む。⏸/▶・シークバー・速度・右下ミニ地図に現在地
   - 進行は「画像の読み込み完了を検知してから」。速度設定は読み込み後にその場を眺める時間

## Google Maps API キーの取得

1. https://console.cloud.google.com/ でプロジェクト作成
2. 「APIとサービス」→「ライブラリ」→ **Maps JavaScript API** を有効化
3. 課金アカウントを紐づけ(クレカ登録が必要。無料枠内なら請求は発生しない)
4. 「認証情報」→ APIキー作成。**キー制限**で「HTTPリファラー」に `http://localhost:8931/*` を設定しておくと安全
5. アプリの「APIキー」ボタンから貼り付け(この端末の localStorage にのみ保存)

個人利用の頻度なら毎月の無料枠に収まる想定。使用量は Cloud Console で確認できる。

## 仕組み

- 地図・道路データ: OpenStreetMap(Leaflet + Overpass API、無料・キー不要)
- ルート生成: クリック地点の最寄りノードから周囲4方向の経由点を最短路でつなぎ一周。
  一度使った道はコストを4倍にして、行きと帰りが同じ道になりにくくしている
- 再生: ルートを13m間隔に分割 → 各点を StreetViewService で最寄りパノラマに吸着 →
  重複を除いた列を順に表示し、進行方向へ視点を補間。動画ファイルは作らない
  (ストリートビュー画像の保存・再配布は規約違反になるため、公式ビューアの自動運転方式)
- 読み込み待ち対策: 不可視の2つ目のビューアで次のパノラマを先読み+PerformanceObserver で
  タイル取得の完了を検知してから次へ進む

## 既知の制約

- 歩道・遊歩道(footway)は除外している。ストリートビューの撮影がない道は自動でスキップ
- パノラマ間の遷移はカット気味(公式ビューアの仕様)。速度「ゆっくり」が一番見やすい
- Overpass API が混んでいると取得に失敗することがある(3系統のミラーを順に試す。
  12秒ずつで打ち切り)→ ダメなら少し待って再クリック
